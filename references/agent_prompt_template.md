# Agent 提示词模板 — 科学引文批量验证

> 将此模板用于每个验证 Agent。替换 `{BATCH_RANGE}`、`{REFERENCES}` 为具体内容。

---

## 标准 Agent 提示词

````markdown
你的任务是验证以下 {COUNT} 条参考文献的准确性。对每条文献，优先使用 PubMed 搜索工具检索，比对作者、标题、期刊、年份、卷(期)、页码是否与数据库中记录一致。

**PubMed 搜索脚本**：`bash ~/.workbuddy/skills/lc-pubmed-search/scripts/search "关键词" 5`

---

需要验证的 {COUNT} 条文献：

{REFERENCES}

---

**验证策略**：

| 文献类型 | 特征 | 验证方法 |
|---------|------|---------|
| 期刊论文 | 含期刊名、卷期页码 | PubMed 脚本搜索标题关键词（4-6个关键词） |
| 中国临床试验 | MR-XX-XX-XXXXXX 备案号 | WebSearch 搜索 "卫健委 备案号" |
| 国际临床试验 | NCT 编号 | WebSearch 搜索 "NCT编号" |
| 中国专利 | CN 开头专利号 | WebSearch 搜索 "专利号 发明人" |
| 国际专利 | US/WO 开头专利号 | WebSearch 搜索 "专利号 inventor" |
| 预印本 | arXiv/bioRxiv 等 | 对应服务器直接查询 |
| 无法定位 | PubMed 未找到 | 降级到 WebSearch 搜索完整标题 |

**搜索词构造规则**：
- 取标题前 4-6 个有区分度的关键词
- 去掉 "a/the/and/of/in/for" 等停用词
- 对于 PubMed 搜索，加上第一作者姓氏
- 示例标题 "Stable intracerebral transplantation of neural stem cells for the treatment of paralysis due to ischemic stroke"
  → 搜索词：`"Zhang stable intracerebral transplantation neural stem cells ischemic stroke"`

**对每条文献输出**：
```
═══════════════════════════════════════════════════════
[N] ✅/⚠️/❌ 状态简要说明
    来源：PubMed/WebSearch/其他
    标题：匹配/差异
    作者：匹配/差异
    期刊：匹配/差异
    年份/卷(期)/页码：匹配/差异
    PMID/DOI：（如可用）
    修正建议：（如有）
═══════════════════════════════════════════════════════
```

**注意事项**：
1. 每条文献用独立的 bash 命令搜索，不要合并
2. 如果 PubMed 返回 "setup_required"，停止并报告
3. 如果搜索返回多条结果，选择标题最匹配的那条
4. 对作者名字的大小写敏感（McCourt ≠ Mcourt）
5. 对标题中的特殊字符仔细核对（希腊字母 β、连字符等）
6. 中国专利需核对：发明人、专利号、申请日、公开日、标题
7. 临床试验备案需核对：备案号、负责人、医院、项目名称
8. 完成后输出总览：验证数/通过数/警告数/未找到数
9. 对不确定的条目标注 [待确认] 而不是强制判定

## 常见问题判定参考

| 发现 | 判定 | 说明 |
|------|------|------|
| 全部字段匹配 | ✅ | 完全通过 |
| 标题大小写差异 | ✅ | 格式差异，非内容错误 |
| 标题有小词增减（the/a） | ✅ | 可忽略 |
| 作者姓名字母大小写 | ⚠️ | 建议修正（如 Mcourt→McCourt） |
| 标题中有词语差异 | ⚠️ | 引文标题可能不准确 |
| 标题完全不对 | ⚠️ | 严重，需更正 |
| 期刊名称完整 vs 缩写 | ✅ | 两者均可接受 |
| 卷期页码有 ±1 偏差 | ⚠️ | 数字错误 |
| 论文完全找不到 | ❌ | 需核实文献真实性 |
| 搜索结果不相关 | ❌ | 可能是错误引用 |
````
