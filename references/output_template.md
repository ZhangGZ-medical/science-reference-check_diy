## DOCX 样式配置

### 页面设置
- 纸张：A4 纵向
- 页边距：上下左右各 2.54 cm
- 字体：Arial（英文）/ 宋体（中文），正文 11pt

### 标题样式
- 报告标题：Arial 22pt，居中，加粗
- 一级标题：Arial 16pt，加粗，2E75B6 蓝色
- 二级标题：Arial 13pt，加粗，333333
- 问题标注：RGB(200, 50, 0) 橙红色

### 表格样式
- 表头：2E75B6 蓝底白字，10pt 加粗
- 数据行：9pt，隔行浅蓝底色 (F2F7FB)
- 边框：单实线 1pt，CCCCCC 灰色

### 颜色映射

| 状态 | 颜色代码 | 用途 |
|------|---------|------|
| ✅ 通过 | #2E7D32 | 通过状态标记 |
| ⚠️ 警告 | #C83200 | 问题状态标记 |
| ❌ 未找到 | #FF0000 | 严重问题标记 |
| 表头 | #2E75B6 | 表格标题行 |
| 斑马条纹 | #F2F7FB | 表格数据行间隔 |

---

## 变量占位符说明

| 占位符 | 说明 | 来源 |
|--------|------|------|
| `{TOTAL}` | 引用总数 | 用户输入统计 |
| `{PASS}` | 通过数量 | Agent 结果汇总 |
| `{WARN}` | 警告数量 | Agent 结果汇总 |
| `{FAIL}` | 未找到数量 | Agent 结果汇总 |
| `{PASS_PCT}` | 通过百分比 | 计算得出 |
| `{SUMMARY}` | 主要问题一句话描述 | 人工/模型总结 |
| `{CONCLUSION_TEXT}` | 结论段落 | 模型生成 |
